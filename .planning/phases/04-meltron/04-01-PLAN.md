Create `scripts/convert_cooltools_IS_to_meltron_IS.py` — converts cooltools output to Meltron IS format.

**CLI:**
- `--input`: cooltools insulation TSV (per chromosome, all distances)
- `--output`: Meltron-format IS TSV path
- `--is-distances`: comma-separated distances (to match column names)

**Cooltools output format (per chrom, all distances):**
```
chrom  start  end  log2_insulation_score_100000  ...  log2_insulation_score_200000  ...
```

**Meltron required format:**
```
chrom  viewpoint  IS_distance  IS
Ghir_A01  4000    100000       0.123
Ghir_A01  4000    200000       0.234
...
```

**Conversion logic:**
1. For each row in cooltools output:
   - For each IS distance in is_distances:
     - `chrom` = original chrom
     - `viewpoint` = start (or midpoint of start/end)
     - `IS_distance` = the distance value
     - `IS` = `log2_insulation_score_{distance}` value from cooltools
2. Melt all distance columns into long format
3. Sort by chrom (natural sort), viewpoint, IS_distance
4. Write to Meltron-format TSV

**Note:** Meltron uses raw insulation scores, not log2 transformed. Check if Meltron.R expects log2 or raw IS — if it expects raw, convert: `IS = 2**log2_IS`. If it expects log2, pass through. Verify from Meltron.R source.

**Input:** one cooltools output TSV per chromosome
**Output:** one Meltron-format IS TSV per sample (all chroms merged)

Create `scripts/prepare_meltron_intervals.py` — converts KNN enriched table to Meltron 4-col interval format.

**CLI:**
- `--enriched`: path to `{comparison}_knn_enriched.tsv`
- `--out`: path to output Meltron intervals TSV
- `--min-significant`: minimum number of metrics that must be FDR < threshold (default: 1, i.e. any strong signal; see note below)
- `--fdr-threshold`: FDR threshold (default: 0.05)

**Meltron interval format (STRICTLY 4 columns):**
```
chrom  start  end  ID
Ghir_A01  0  300000  Ghir_A01_000001
Ghir_A01  32000  332000  Ghir_A01_000002
...
```

**No extra columns.** If mapping back to window_id is needed, emit a separate `*_interval_map.tsv` alongside.

**Logic:**
1. Read knn_enriched.tsv
2. Compute BH-FDR for 5 p-value columns (copy benjamini_hochberg from compute_knn_empirical_pvalue.py)
3. Filter: count of FDR < threshold across 5 columns >= `--min-significant`
   - **Note on `--min-significant` default:** Default to 1 (any strong indicator) to avoid post-selection bias — Meltron score itself is the secondary filter, not the FDR threshold
   - If min_significant=1: all windows with >=1 metric FDR<0.05 enter Meltron
   - This gives Meltron a broader candidate set; stronger filtering comes in merge step
4. Assign ID = `{chrom}_{window_id}` (from knn_enriched window_id column)
5. Output only 4 columns: chrom, start, end, ID

**Also emit:** `{out}.map.tsv` with columns `(ID, chrom, start, end, window_id, n_significant_metrics)` for downstream joining back to original window metadata.

Create `scripts/merge_meltron_scores.py` — merges decondensation + condensation results into one TSV.

**CLI:**
- `--comparison`: comparison name
- `--decondensation`: path to decondensation result TSV
- `--condensation`: path to condensation result TSV
- `--interval-map`: path to the `*_interval_map.tsv` from prepare_meltron_intervals.py
- `--out`: output TSV path
- `--score-threshold`: melting_score threshold for flagging (default 5.0, advisory only)
- `--log-file`: log file path

**Logic:**
1. Read decondensation and condensation TSVs
2. Merge on (chrom, start, end, ID)
3. For each interval compute:
   - `meltron_melting_score` = decondensation melting_score
   - `meltron_compaction_score` = condensation melting_score
   - `meltron_best_score` = max(melting_score, compaction_score)
   - `meltron_best_direction` = "decondensation" if melting_score >= compaction_score else "condensation"
   - `meltron_is_significant` = 1 if meltron_best_score >= threshold else 0 (advisory flag)
4. Left join with interval_map to bring back window_id and n_significant_metrics
5. Output columns: `(chrom, start, end, ID, meltron_melting_score, meltron_compaction_score, meltron_best_score, meltron_best_direction, meltron_is_significant, window_id, n_significant_metrics)`

**Handling empty input:** If one of the Meltron results is empty (no valid intervals), merge with empty DataFrame and continue.

**Note:** `meltron_is_significant` is an advisory flag. Do not interpret as genome-wide significance.

Create `rules/meltron.smk` — one rule that runs both decondensation and condensation.

**Architecture: single rule, two Meltron runs in shell block, then merge.**

**rule meltron_per_comparison:**
- input:
  - lambda w: checkpoints.compute_IS.get(sample=w.comparison.split("_vs_")[0]).output.is_file
  - lambda w: checkpoints.compute_IS.get(sample=w.comparison.split("_vs_")[1]).output.is_file
  - knn_enriched = OUTDIR + "/knn_empirical_pvalue/{comparison}/{comparison}_knn_enriched.tsv"
  - script_prepare = SCRIPT_DIR + "/scripts/prepare_meltron_intervals.py"
  - script_run = SCRIPT_DIR + "/scripts/run_meltron.py"
  - script_merge = SCRIPT_DIR + "/scripts/merge_meltron_scores.py"
- output:
  - manifest = OUTDIR + "/logs/meltron/{comparison}.done"
  - intervals = OUTDIR + "/meltron/{comparison}/{comparison}_intervals.tsv"
  - interval_map = OUTDIR + "/meltron/{comparison}/{comparison}_interval_map.tsv"
  - decond = OUTDIR + "/meltron/{comparison}/{comparison}_decondensation.tsv"
  - condens = OUTDIR + "/meltron/{comparison}/{comparison}_condensation.tsv"
  - merged = OUTDIR + "/meltron/{comparison}/{comparison}_meltron_merged.tsv"
- log: OUTDIR + "/logs/meltron/{comparison}.log"
- benchmark: OUTDIR + "/benchmark/meltron/{comparison}.tsv"
- threads: config["parallel"]["threads_per_job"]
- params:
  - outdir = OUTDIR
  - cutoff_na = config["meltron"]["cutoff_na"]
  - score_threshold = config["meltron"]["score_threshold"]
  - min_significant = 1  # any one metric FDR < 0.05 → broad candidate set
- conda: "../env/meltron.yaml"
- shell:
  1. Extract sample names via bash string split
  2. Prepare intervals from knn_enriched.tsv
  3. Run decondensation Meltron
  4. Run condensation Meltron
  5. Merge results

```bash
set -euo pipefail

COMPARISON="{wildcards.comparison}"
SAMPLE_A="${{COMPARISON_STR%%_vs_*}}"
SAMPLE_B="${{COMPARISON_STR#*_vs_}}"

# Bash extract (Snakemake wildcard accessible via shell)
COMPARISON_STR="{wildcards.comparison}"
SAMPLE_A="${{COMPARISON_STR%%_vs_*}}"
SAMPLE_B="${{COMPARISON_STR#*_vs_}}"

IS_A="{params.outdir}/IS/${{SAMPLE_A}}/${{SAMPLE_A}}_IS.tsv"
IS_B="{params.outdir}/IS/${{SAMPLE_B}}/${{SAMPLE_B}}_IS.tsv"

mkdir -p "{params.outdir}/meltron/$COMPARISON"

# Step 1: prepare Meltron intervals
python {input.script_prepare} \
    --enriched {input.knn_enriched} \
    --out "{output.intervals}" \
    --min-significant {params.min_significant} \
    --fdr-threshold 0.05

# Step 2: decondensation
python {input.script_run} \
    --comparison "$COMPARISON" \
    --is-a "$IS_A" \
    --is-b "$IS_B" \
    --genomic-intervals "{output.intervals}" \
    --outfile "{output.decond}" \
    --comparison-direction decondensation \
    --cutoff-na {params.cutoff_na}

# Step 3: condensation
python {input.script_run} \
    --comparison "$COMPARISON" \
    --is-a "$IS_A" \
    --is-b "$IS_B" \
    --genomic-intervals "{output.intervals}" \
    --outfile "{output.condens}" \
    --comparison-direction condensation \
    --cutoff-na {params.cutoff_na}

# Step 4: merge both directions
python {input.script_merge} \
    --comparison "$COMPARISON" \
    --decondensation "{output.decond}" \
    --condensation "{output.condens}" \
    --interval-map "{output.interval_map}" \
    --out "{output.merged}" \
    --score-threshold {params.score_threshold}

touch "{output.manifest}"
```
